# Online Exams
Base funcional para una plataforma de exámenes en línea.

## Stack
ASP.NET Core 8 + EF Core + PostgreSQL; React/Vite; Docker; Terraform/Azure; GitHub Actions; SonarCloud; Snyk; Semgrep; Mermaid.

## Ejecutar localmente
1. Instala Docker Desktop.
2. Ejecuta `docker compose up --build`.
3. API/Swagger: `http://localhost:8080/swagger`.
4. Frontend: `http://localhost:3000`.

## Conexiones pendientes
Configura tus credenciales/secretos de Azure, SonarCloud y Snyk en GitHub. Completa los recursos Azure específicos en `infrastructure/main.tf` según tu suscripción y nombres disponibles.
